# Lista 1 – Estrutura de Dados em Java

Este repositório contém a **Lista 1 de exercícios da disciplina de Estrutura de Dados**, desenvolvida em **Java**.  
O projeto tem como objetivo reforçar os fundamentos da linguagem Java e da lógica de programação, servindo como base para o estudo de estruturas de dados.

Cada exercício está implementado em uma **classe Java independente**, localizada no diretório `src`.

---

## 📚 Exercícios

Os exercícios abordam conceitos fundamentais da programação em Java, como:

- Entrada e saída de dados
- Tipos primitivos
- Operações aritméticas
- Lógica sequencial
- Estruturas de controle
- Organização do código em classes

### Exercícios implementados

- **Ex1.java**  
  Exercício introdutório que realiza leitura de dados via teclado e executa operações básicas de processamento, com exibição do resultado no console.

- **Ex2.java**  
  Programa que simula um saque bancário. A partir de um valor inteiro informado pelo usuário, o sistema calcula a quantidade mínima de notas de R$ 50, R$ 20 e R$ 10 necessárias para compor o valor do saque.

- **Ex3.java**  
  Exercício voltado ao processamento de dados informados pelo usuário, aplicando lógica sequencial e operações aritméticas para resolver o problema proposto, com exibição do resultado no console.

Para executar o projeto, é necessário ter instalado:

- **Java JDK** (versão 11 ou superior)
- **Git** (opcional, para clonar o repositório)
- Uma IDE Java, como:
  - IntelliJ IDEA
  - Eclipse
  - VS Code com extensão Java
